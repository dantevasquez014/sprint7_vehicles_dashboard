# Análisis de Vehículos - Panel de Control
Este proyecto es una aplicación web interactiva desarrollada con Python y Streamlit que permite analizar un conjunto de datos de anuncios de venta de coches en Estados Unidos.

La aplicación incluye gráficos interactivos generados con Plotly Express, permitiendo a los usuarios visualizar:
- Un histograma con la distribución del kilometraje (odómetro).
- Un gráfico de dispersión relacionando el kilometraje con el precio.
